PX4 AI Orchestration
Harness

Accept natural-language mission intent. Decompose into a validated multi-vehicle plan. Enforce hard constraints deterministically. Require human authorization. Dispatch over ROS 2 and MAVLink 2 against PX4 SITL.

View on GitHub FastAPI Backend PX4 SITL ROS 2 Humble MAVLink 2
Step 1

Intent Ingestion

POST natural-language mission text to /intent. The LLM decomposer generates a structured Mission Intent Graph (MIG).

Step 2

Deterministic Validation

The constraint checker validates altitude bounds, geofence containment, RTL requirements, and waypoint integrity — no LLM involved.

Step 3

Human Authorization

A human operator reviews the plan and either authorizes or rejects it. Authorization is recorded in the immutable audit log.

Step 4

Dual-Transport Dispatch

Vehicle Action Lists (VALs) are dispatched to each vehicle via ROS 2 (primary) and MAVLink 2 (secondary) transport stubs.

API Endpoints

MethodPathDescription
POST /intent Submit natural-language mission intent. Returns mission_id immediately; planning runs in background.
GET /plan/{mission_id} Poll mission status and retrieve the full MIG once planning completes.
POST /authorize/{mission_id} Human authorization gate. Authorized missions proceed to dispatch; rejected missions are aborted.
GET /missions List all missions with summary status.
GET /audit/{mission_id} Retrieve the immutable JSONL audit log for a mission.
GET /ui Web authorization dashboard (Jinja2 UI).
GET /docs Interactive OpenAPI documentation.
