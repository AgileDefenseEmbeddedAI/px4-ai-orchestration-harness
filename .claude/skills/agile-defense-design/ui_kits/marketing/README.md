# Marketing UI Kit

Recreates the Agile Defense public site (homepage) at its 1728 px native
design width. Components: `Navbar`, `Hero`, `PurposeSection`,
`CapabilityCards`, `CultureSection`, `AgileLabsSection`, `FinalCTA`, `Footer`.

Built from live brand assets and the component library in
`reference/component-library.html`. Open `index.html`.
